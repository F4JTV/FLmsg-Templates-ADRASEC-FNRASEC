Aide a la redaction


        

          Le formulaire s'adapte au type de message choisi en haut de page.
        


        
Message d'ambiance

        
Premier compte rendu depuis le terrain, transmis des l'arrivee sur les lieux.
          Il donne une premiere image de la situation.


        
Message de situation

        
Compte rendu periodique qui actualise l'ambiance : evolution, moyens, besoins.


        
Message encapsule

        
Transport d'un message redige par une autorite. Le radioamateur n'en est pas
          l'auteur : il indique l'autorite d'origine et l'autorite destinataire, puis
          recopie le texte sans le modifier.


        
Procedure codifiee

        
Compte rendu normalise de l'etat de la station, transmis a l'ouverture du
          reseau ou sur demande du gestionnaire.

        
    
          
  • PAPA : position, commune et coordonnees. Le format transmis
            accompagne les coordonnees.
    • 
          
  • SIERRA : station fixe, mobile ou portable.
    • 
          
  • GOLF : gammes exploitables, plusieurs choix possibles.
    • 
          
  • ECHO : source d'alimentation electrique.
    • 
          
  • ALPHA : autonomie restante, en heures.
    • 
          
  • DELTA : delai avant d'etre operationnel.
    • 
        


        
Les quatre rubriques

        
    
          
  • Je suis : ou je me trouve, avec quels moyens.
    • 
          
  • Je vois : ce que j'observe, sans interpretation.
    • 
          
  • Je fais : les actions que j'ai engagees.
    • 
          
  • Je demande : les moyens ou instructions dont j'ai besoin.
    • 
        


        
Envoi avec FLmsg

        
    
          
  1. Cliquez sur Transmettre a FLmsg en bas du formulaire : les donnees
            passent dans FLmsg et le navigateur affiche le message en lecture.
    2. 
          
  2. Enregistrez le message dans FLmsg (fichier .k2s).
    3. 
          
  3. Choisissez le mode numerique puis cliquez sur AutoSend :
            fldigi transmet le message.
    4. 
        


        
Accuse de reception

        
FLmsg n'envoie aucun accuse automatique. La station destinataire ouvre le
          message recu, clique sur Preparer l'accuse de reception, puis remplit
          le formulaire AR ADRASEC.


        

          Tous les accents et caracteres speciaux sont convertis en ASCII a l'envoi :
          les modes numeriques de fldigi (MT63, Olivia...) ne transmettent pas toujours
          les caracteres accentues.
        


        

          Seules les valeurs des champs sont transmises. Le destinataire doit disposer
          du meme fichier ADRASEC_Message.html dans le dossier CUSTOM de FLmsg.
        


        
Champs

        
    
          
  • N° du message : propose par un compteur local au navigateur,
            modifiable.
    • 
          
  • Date / Heure : heure locale, renseignee automatiquement et modifiable.
    • 
          
  • Origine : indicatif de la station emettrice (fond jaune), memorise
            d'un message a l'autre.
    • 
          
  • Destinataire(s) : indicatifs separes par des points-virgules.
    • 
          
  • Autorites (fond vert) : uniquement pour un message encapsule.
