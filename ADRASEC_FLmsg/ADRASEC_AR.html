Accuse de reception


        

          Pour pre-remplir ce formulaire, ouvrez d'abord le message recu dans FLmsg
          (View Form) et cliquez sur Preparer l'accuse de reception. Le numero,
          le destinataire et la reference sont alors repris ici.
        


        
Champs pre-remplis

        
    
          
  • N° de l'AR : numero du message accuse. Modifiable.
    • 
          
  • Date / Heure : instant de l'accuse, en heure locale.
    • 
          
  • Origine : votre indicatif, memorise d'un envoi a l'autre.
    • 
          
  • Destinataire : la station qui a emis le message accuse.
    • 
          
  • Reference : priorite, type, numero et sujet du message recu.
    • 
        


        
Si la page du message a ete ouverte hors de FLmsg (fichier local), la
          reference est seulement copiee : collez-la (Ctrl+V) dans le champ Reference.


        
Champs a saisir

        
    
          
  • Priorite : en principe Routine, sauf si l'accuse lui-meme est urgent.
    • 
          
  • Commentaire : ce que vous avez fait du message. Une remise a l'autorite
            destinataire se mentionne ici, avec son heure.
    • 
        


        
Envoi avec FLmsg

        
    
          
  1. Cliquez sur Transmettre a FLmsg en bas du formulaire.
    2. 
          
  2. Enregistrez l'accuse dans FLmsg (fichier .k2s).
    3. 
          
  3. Cliquez sur AutoSend : fldigi transmet l'accuse.
    4. 
        


        

          FLmsg n'envoie aucune confirmation automatique : seul cet accuse confirme la
          prise en compte du message par l'operateur. Les accents sont convertis en
          ASCII a l'envoi.
